# JupyterLab Moonlight

A dark blue theme for JupyterLab and Jupyter Notebook 7+, inspired by the [Moonlight VS Code Theme](https://github.com/atomiks/moonlight-vscode-theme) and [github-moonlight](https://github.com/Brettm12345/github-moonlight).

## Features

- **Moonlight Palette**: Deep navy editor surfaces (`#191b28`), elevated cards (`#222436`), and soothing canvas backgrounds (`#1e2030`).
- **Syntax Highlighting**:
  - Keywords: Purple (`#c597f9`)
  - Strings: Green (`#c3e88d`)
  - Numbers and constants: Orange (`#ff995e`)
  - Functions and definitions: Cyan (`#86e1fc`)
  - Builtins: Pink (`#fca7ea`)
  - Comments: Muted indigo (`#828bb8`)
- **Clean Interface**: Softened borders (`#2f334d`), blue accent controls (`#82aaff`), and subtle row hover highlights.
- **Compatibility**: Supports JupyterLab 4+ and Jupyter Notebook 7+.

## Installation

### From GitHub

```bash
pip install git+https://github.com/snelow/jupyterlab-moonlight.git
```

### From PyPI

```bash
pip install jupyterlab-moonlight
```

### Local Development

```bash
git clone https://github.com/snelow/jupyterlab-moonlight.git
cd jupyterlab-moonlight
pip install .
```

---

## Activation

1. Start your notebook environment:
   ```bash
   jupyter lab
   # or
   jupyter notebook
   ```
2. Navigate to **Settings ➔ Theme ➔ JupyterLab Moonlight** in the top menu.
